TradeVault · Android UI

Matched to the website

The same four pastel blocks, the same near-black slab for the primary action, the same editorial page head and the same hairline cards — translated to a 390 dp phone. Dark is the default; the light phone is the identical layout under the OS light theme. Scroll inside any phone.

What changed

In-screen display headers replace the Android toolbar. Page padding is 18, cards are 18-radius with 18 padding, and numbers use tabular figures so P&L columns line up.

What stayed honest

Figures come from the same engine: open trades stay out of realised stats, undefined values read N/A, and totals are never summed across currencies. The app itself shows your records — the sample numbers here exist only in this preview.

Tokens

The palette is copied value-for-value from app.css: #131313 canvas, #3d2a22 coral, #f9b69f coral ink, #a78bfa accent. No new colours were invented for the phone.
